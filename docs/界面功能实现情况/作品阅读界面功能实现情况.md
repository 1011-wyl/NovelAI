# 作品阅读界面 · 核心功能实现情况

> 盘点对象：侧栏「作品阅读」三栏工作台  
> 时间：2026-09-29

---

## 总览

主闭环已通：**打开 READY 章节 → 编辑并自动保存草稿 → 选区右键交给 AI → 批准进草稿 → 应用修订成正式版 → 后续章安全重置**。

当前默认多为**离线安全模式**（本地确定性 AI）；配置 DeepSeek 并切在线后走同一套接口。

| 状态 | 含义 |
|---|---|
| 已实现 | 前后端可用，可演示 |
| 部分实现 | 主流程有，体验或覆盖不完整 |
| 未实现 | 设计有、当前没有 |

---

## 核心功能实现情况

| 核心功能 | 实现情况 | 一句话说明 |
|---|---|---|
| 三栏工作台（目录 / 正文 / AI） | **已实现** | 全幅布局，阅读页隐藏顶栏 |
| 书籍选择器切换项目 | **已实现** | 左栏顶部封面卡片下拉 |
| 章节列表与 READY 筛选 | **已实现** | 全部 / READY / 其他 |
| READY 章节编辑标题与正文 | **已实现** | 非 READY 只读 |
| 工作草稿自动保存 | **已实现** | 约 800ms 防抖；不改正式正文 |
| 放弃草稿 | **已实现** | 回到当前正式正文 |
| 版本历史并恢复为草稿 | **部分实现** | 可恢复；无版本正文预览 |
| 选区右键快捷改写 | **已实现** | 润色 / 精简 / 扩写等；仅右键弹出 |
| AI 顾问 / 共创 / 编辑三模式 | **已实现** | 编辑模式才出待批修改 |
| AI 差异预览、批准、拒绝 | **已实现** | 批准只进草稿，不直接改正式版 |
| 会话回滚 | **已实现** | 「回滚到这里」；有手工编辑会冲突 |
| 应用修订（提交正式版） | **已实现** | 生成新版本并清草稿 |
| 后续章节安全重置 | **已实现** | 保留 `RESET_ARCHIVE`，异于「重做」删除 |
| 离线 / 在线 AI | **已实现** | 离线可演示；在线需配置 Key |
| 冲突检测（版本不一致） | **部分实现** | 有 409 提示；缺一键重载/复制本地 |

## 主闭环是否打通

```text
打开 READY 章
  → 编辑自动进工作草稿          ✅
  → 右键选区发 AI               ✅
  → 看 diff，批准或拒绝         ✅
  → 批准结果写入工作草稿        ✅
  →「应用修订」生成正式新版本   ✅
  → 后续章安全重置并保留历史    ✅
```

## 本期明确不做（不是漏做）

- 富文本 / 图片 / Markdown 渲染  
- 多人协作与账号  
- AI 流式输出  
- 同时编辑多章  
- 自动重写全部后续正文
